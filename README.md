# 🎬 Movie Site API

Projeto web desenvolvido com **Node.js + Express + EJS**, que consome a API do TMDB para exibir filmes populares com paginação.

---

## 🚀 Funcionalidades

* 🔥 Listagem de filmes populares
* 🔢 Paginação dinâmica
* 🌎 Integração com API do TMDB
* 🎨 Renderização com EJS
* 📱 Layout simples e funcional

---

## 🛠️ Tecnologias utilizadas

* Node.js
* Express
* EJS (Embedded JavaScript Templates)
* Axios
* TMDB API

---

## 📂 Estrutura do projeto

```
movie-site-api/
│
├── controllers/        # Lógica da aplicação
├── routes/             # Definição de rotas
├── views/              # Páginas EJS
├── public/             # Arquivos estáticos (CSS, imagens)
├── app.js              # Arquivo principal
├── package.json
```

---

## ⚙️ Como rodar o projeto

### 1. Clone o repositório

```
git clone https://github.com/seu-usuario/movie-site-api.git
```

---

### 2. Instale as dependências

```
npm install
```

---

### 3. Configure as variáveis de ambiente

Crie um arquivo `.env` na raiz:

```
API_KEY=sua_chave_tmdb
```

---

### 4. Inicie o servidor

```
npm start
```

---

### 5. Acesse no navegador

```
http://localhost:3000
```

---

## 🔐 Variáveis de ambiente

| Variável | Descrição            |
| -------- | -------------------- |
| API_KEY  | Chave da API do TMDB |
